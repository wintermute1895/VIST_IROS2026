# 频率监控功能使用指南

## 概述

已在 `vist_filter_node.py` 中添加了完整的频率监控功能，实时打印所有关键频率信息。

## 监控的频率

1. **外骨骼接收频率**：滤波节点接收外骨骼数据的频率
2. **视觉接收频率**：滤波节点接收视觉数据的频率
3. **定时器回调频率**：滤波节点内部定时器的实际运行频率
4. **滤波输出频率**：滤波节点发布滤波后数据的频率
5. **机械臂反馈频率**：机械臂发送状态反馈的频率

## 输出格式

每秒会自动打印一次频率报告，格式如下：

```
================================================================================
                              频率监控报告
================================================================================
名称                   频率 (Hz)         总计数           窗口大小
--------------------------------------------------------------------------------
外骨骼接收                  80.12 Hz         1234            100
视觉接收                     0.00 Hz            0              0
定时器回调                  80.05 Hz         1235            100
滤波输出                    80.05 Hz         1235            100
机械臂反馈                  79.98 Hz         1233            100
================================================================================

异常警告:
  ⚠️ 视觉数据接收频率过低: 0.00 Hz
================================================================================
```

在 `vist_filter_node.py` 的第 358 行，需要修改机械臂反馈话题名称：

```python
# 订阅机械臂反馈话题（用于频率监控）
robot_feedback_topic = '/robot_joint_states'  # 修改为实际的机械臂反馈话题
```

**常见的机械臂反馈话题名称**：
- `/robot_joint_states`
- `/joint_states`
- `/lbot_arm/joint_states`
- `/left_arm/joint_states`

请根据你的实际系统修改为正确的话题名称。

## 使用方法

### 1. 启动滤波节点

```bash
cd /home/ilex/Dev/VIST
ros2 launch bringup vist_filter.launch.py
```

### 2. 观察频率输出

启动后，终端会每秒自动打印频率报告。

### 3. 诊断问题

根据频率报告，可以诊断以下问题：

#### 问题 1：外骨骼接收频率过低
```
外骨骼接收                   5.23 Hz          523            100
```
**可能原因**：
- 外骨骼节点未启动或崩溃
- 外骨骼话题名称配置错误
- 外骨骼发布频率本身就很低

**解决方法**：
```bash
# 检查外骨骼话题是否存在
ros2 topic list | grep arm_joint_control

# 检查外骨骼话题的实际频率
ros2 topic hz /left_arm_joint_control
```

#### 问题 2：定时器回调频率异常
```
定时器回调                  40.12 Hz         1234            100
```
**可能原因**：
- 滤波器计算耗时过长，导致定时器回调被延迟
- 系统负载过高
- IK 求解器性能问题

**解决方法**：
- 检查 FSM 调试输出，看是否有大量的 IK 求解失败
- 减少调试打印信息
- 优化滤波器算法

#### 问题 3：滤波输出频率与定时器回调频率不一致
```
定时器回调                  80.05 Hz         1235            100
滤波输出                    40.12 Hz          618            100
```
**可能原因**：
- 滤波器内部有条件判断，导致部分回调没有发布输出
- 输入数据验证失败（如关节数量不正确）
- 滤波器抛出异常

**解决方法**：
- 检查日志中的警告和错误信息
- 确保输入数据格式正确

#### 问题 4：机械臂反馈频率过低
```
机械臂反馈                   0.00 Hz            0              0
```
**可能原因**：
- 机械臂反馈话题名称配置错误
- 机械臂控制器未启动
- 机械臂未连接

**解决方法**：
```bash
# 检查机械臂反馈话题是否存在
ros2 topic list | grep joint_states

# 检查机械臂反馈话题的实际频率
ros2 topic hz /robot_joint_states
```

## 频率监控器参数

可以在 `vist_filter_node.py` 中调整频率监控器的参数：

```python
# 滑动窗口大小（用于计算平均频率）
self.freq_exo_receive = FrequencyMonitor(window_size=100, name="外骨骼接收")

# 频率打印间隔（秒）
self.freq_print_interval = 1.0  # 每秒打印一次
```

**参数说明**：
- `window_size`：滑动窗口大小，越大则频率计算越平滑，但响应越慢
- `freq_print_interval`：打印间隔，建议 1-5 秒

## 注意事项

1. **性能影响**：频率监控本身的性能开销很小（每次 tick 只是记录时间戳），不会影响系统性能。
2. **线程安全**：所有频率监控器都使用了线程锁，确保在多线程环境下安全使用。
3. **滑动窗口**：频率计算基于滑动窗口，因此启动后需要等待窗口填满（约 1-2 秒）才能得到准确的频率值。
4. **机械臂话题**：务必修改机械臂反馈话题名称为实际使用的话题。

## 常见问题

### Q: 为什么启动后频率显示为 0？
A: 启动后需要等待滑动窗口填满（约 1-2 秒），之后频率值会逐渐稳定。

### Q: 如何修改打印间隔？
A: 修改 `self.freq_print_interval` 的值，单位为秒。

### Q: 频率监控会影响系统性能吗？
A: 不会。频率监控的开销非常小，每次 tick 只是记录一个时间戳。

### Q: 如何查看某个话题的实际频率？
A: 使用 ROS 2 命令：`ros2 topic hz <topic_name>`
