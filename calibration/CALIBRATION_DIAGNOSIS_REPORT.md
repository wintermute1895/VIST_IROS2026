# 手眼标定系统问题报告

## 诊断日期
2026-02-10

## 诊断结果总结

### ❌ 关键问题
**所有机械臂位姿完全相同，导致手眼标定失败**

### 详细诊断

#### 1. 机械臂位姿数据 ❌
- **状态**: 失败
- **问题**: 所有15个位姿完全相同
- **位姿值**: `[x=0.5, y=0.0, z=0.3, rx=0, ry=0, rz=0]`
- **影响**: 手眼标定算法无法计算相机与末端执行器的相对变换

#### 2. 图像数据 ✓
- **状态**: 正常
- **数量**: 15张图像
- **尺寸**: 640 x 480
- **格式**: uint8

#### 3. ChArUco 板检测 ✓
- **状态**: 正常
- **检测角点数**: 24个
- **说明**: 标定板配置正确，检测算法工作正常

#### 4. 标定结果 ❌
- **状态**: 失败
- **问题**: 标定矩阵是单位矩阵
- **平移向量**: [0, 0, 0]
- **说明**: 标定算法认为相机和末端执行器在同一位置

#### 5. 误差统计 ❌
- **状态**: 失败
- **平均误差**: 244.876 像素
- **标准差**: 41.360 像素
- **正常范围**: < 5 像素
- **说明**: 误差远超正常范围，标定完全无效

## 根本原因

使用了 `MockRobotInterface` 进行数据采集，该接口返回固定的机械臂位姿：

```python
# 在 robot_interface.py 中
class MockRobotInterface(RobotInterface):
    def __init__(self):
        self.current_x = 0.5  # 固定值
        self.current_y = 0.0  # 固定值
        self.current_z = 0.3  # 固定值
        self.current_rx = 0.0 # 固定值
        self.current_ry = 0.0 # 固定值
        self.current_rz = 0.0 # 固定值
```

## 解决方案

### 方案1: 使用真实机械臂（推荐）

1. **修改数据采集脚本** (`data_collection.py`)
   ```python
   # 替换这一行：
   robot = MockRobotInterface()

   # 改为：
   from robot_interface import LinkerArmInterface
   robot = LinkerArmInterface(
       tcp_host="192.168.10.21",  # 你的机器人IP
       arm_side="right"
   )
   ```

2. **采集数据要求**
   - 至少10-15个不同的位姿
   - 每个位姿都要能看到标定板
   - 位姿要有足够的变化：
     - 位置变化：至少在 X、Y、Z 三个方向各移动 10-20cm
     - 姿态变化：至少旋转 20-30 度
   - 避免位姿过于相似

3. **重新采集数据**
   ```bash

   ```

4. **重新运行标定**
   ```bash

   ```

5. **验证标定结果**
   ```bash

   ```

### 方案2: 修改 MockRobotInterface（仅用于测试）

如果暂时没有真实机械臂，可以修改 `MockRobotInterface` 使其返回不同的位姿：

```python
class MockRobotInterface(RobotInterface):
    def __init__(self):
        self.pose_index = 0
        # 预定义多个不同的位姿
        self.poses = [
            (0.5, 0.0, 0.3, 0.0, 0.0, 0.0),
            (0.5, 0.1, 0.3, 0.1, 0.0, 0.0),
            (0.5, -0.1, 0.3, -0.1, 0.0, 0.0),
            (0.6, 0.0, 0.3, 0.0, 0.1, 0.0),
            (0.4, 0.0, 0.3, 0.0, -0.1, 0.0),
            # ... 添加更多不同的位姿
        ]

    def get_current_pose(self):
        x, y, z, rx, ry, rz = self.poses[self.pose_index % len(self.poses)]
        self.pose_index += 1
        return self.pose_to_matrix(x, y, z, rx, ry, rz)
```

**注意**: 这种方法仅用于测试代码逻辑，不能用于实际标定！
