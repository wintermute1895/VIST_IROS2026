## 意图因子计算

头顶相机（348122071157）负责提供以下数据用于意图因子计算：

1. **手部位置和速度** (`/hand_pose`)
   - 用于计算运动能量 α_vel
   - 用于计算方向对齐 α_dir

2. **目标物体位置** (如果启用 AprilTag/ArUco 检测)
   - 用于计算几何势能 α_geo
   - 用于计算手与目标的距离

3. **深度信息** (`/camera/depth/image_raw`)
   - 用于 3D 位置估计
   - 用于场景理解

## 相机验证

检查相机是否正常工作：

```bash
# 列出所有相机
rs-enumerate-devices

# 检查相机话题
ros2 topic list | grep camera

# 查看相机图像（需要启动相机后）
ros2 run rqt_image_view rqt_image_view
```

## 故障排除

### 问题: 启动相机时选择了错误的相机

**解决方案**: 
```bash
# 明确指定头顶相机序列号
./scripts/start_camera.sh 348122071157
```

### 问题: 两个相机同时启动导致冲突

**解决方案**: 
只启动一个相机用于数据采集。如果需要同时使用两个相机，需要为第二个相机配置不同的命名空间。
