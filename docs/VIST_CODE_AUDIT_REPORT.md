**物理意义**:

#### 2.2.2 虚拟引导噪声 R_virtual(α, δ)

**实现** (Lines 323-354):
```python
R_virtual(α) = R_min/(α + ε) + γ_c × ||δ||²
```

**物理意义**:
- α→1: 磁吸引效应（低方差）
- 冲突检测: δ = Δθ_human - Δθ_virtual

**参数**: R_min=1e-3, γ_c=1.0

**验证**: ✅ 符合论文反比例+冲突项策略

## 3. 流形约束执行（Q矩阵）

### ⚠️ **简化实现 - 与论文理论有偏差**

### 3.1 当前实现：雅可比冻结机制

**文件位置**: [src/core/vist_kalman_filter.py:170-245](../src/core/vist_kalman_filter.py)

**方法**:
1. 计算雅可比矩阵 J 确定各关节对Z方向的贡献
2. 当 α > 0.8 时激活Z轴锁定
3. 对非插入自由度应用冻结因子
4. 修改Q矩阵元素: `Q_i *= freeze_factor`

**优点**:
- 计算高效
- 易于理解和调试
- 实际效果良好

### 3.2 论文理论：李代数零空间投影

**论文描述** (VIST_METHOD_COMPLETE_FRAMEWORK.md Part 4):
```
流形约束应通过SE(3)李代数投影实现:
x̂ = x̂ + K·P_null·(z - H·x̂)
其中 P_null 是约束流形的零空间投影矩阵
```

**缺失组件**:
- ❌ 显式流形定义 M ⊂ SE(3)
- ❌ 李代数约束协方差矩阵 Σ_se(3)
- ❌ 零空间投影算子 P_null
- ❌ 任务特定约束矩阵

**评估**:
- 当前实现是**功能等效的简化版本**
- 对于Z轴插入任务，雅可比冻结与零空间投影效果相近
- 缺乏理论完备性，但工程实用性强

**建议**:
- 如需发表论文，应补充完整李代数框架
- 如仅工程应用，当前实现已足够
