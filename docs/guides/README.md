# 操作指南

这里包含系统使用的详细指南文档。

## 可用指南

### [real_robot_startup_guide.sh](./real_robot_startup_guide.sh)
真机双臂完整启动指南，包含：
- 启动顺序
- 验证步骤
- 安全注意事项
- 故障排查
- 紧急停止方法

### [rqt_usage_guide.sh](./rqt_usage_guide.sh)
RQT工具使用指南，包含：
- 插件加载方法
- 常用插件介绍
- 数据可视化技巧
- 命令行替代方案

## 使用方法

这些指南是可执行的shell脚本，会在终端中显示格式化的文档：

```bash
./real_robot_startup_guide.sh
./rqt_usage_guide.sh
```

或者直接用文本编辑器查看内容。
