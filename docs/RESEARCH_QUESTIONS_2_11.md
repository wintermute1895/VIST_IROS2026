## 问题清单

### 1. α的数学建模问题：手内姿态对齐

**问题描述**:
当前α的三组分（距离、速度、方向对齐）无法处理TCP不确定性问题。每次抓取USB时，尖端位置不确定，导致无法精确对齐插口。

**已有解决方案** ✅:
在 [MATHEMATICAL_THEORY.md](MATHEMATICAL_THEORY.md) 2.4节中，我们引入了**置信度状态变量 c(t)** 和**冲突驱动方差膨胀**机制：

```
R_virtual(α, δ, c) = R_min/(α + ε) × 1/(c + ε) + λ_escape × ||δ||²

dc/dt = {
  -λ_decay × ||δ|| × c     (冲突时快速衰减)
  λ_recover × (1 - c)      (无冲突时缓慢恢复)
}
```

**核心思想**: 不试图完美标定TCP，而是允许操作者通过"挣脱-微调"机制修正偏差。

**理论优雅性**:
- ✅ 符合共享自主（Shared Autonomy）理论
- ✅ 有完整的数学证明（定理2.2, 2.3）
- ✅ 可泛化到其他不确定性场景

---

### 2. 挣脱机制的死循环问题

**问题描述**:
如果只有冲突项 λ_escape × ||δ||²，当操作者微调到正确位置后（δ → 0），系统会重新吸附到错误位置，形成死循环。

**已有解决方案** ✅:
置信度状态变量 c(t) 提供"记忆效应"：
- 检测到冲突时，c快速衰减（τ_decay ≈ 0.2s）
- 即使δ → 0，由于c很小，R_virtual仍然很大，系统不会重新吸附
- c缓慢恢复（τ_recover ≈ 2.0s），给操作者充足的微调时间

**实验验证设计**:
- 对照组A（无冲突项）: 0%成功率
- 对照组B（有冲突项，无置信度）: <30%成功率（死循环）
- 对照组C（完整VIST）: >95%成功率

**分析**:

**当前方案的泛化性评估**:

| 方案 | 泛化性 | 理论优雅性 | 工程复杂度 | 推荐度 |

**为什么冲突驱动方差膨胀是泛化的？**

**建议**:

### 5. 两种应用的不同问题

**模仿学习数据采集 vs 工业遥操作装配**

| 维度 | 模仿学习数据采集 | 工业遥操作装配 |
|-----|----------------|--------------|
| **核心目标** | 采集高质量示教数据 | 完成精密装配任务 |
| **成功率要求** | 80-90%（可重试） | >99.9%（不可失败） |
| **精度要求** | 中等（5mm） | 极高（<1mm） |
| **成本约束** | 极严格（$500） | 宽松（$50k可接受） |
| **人机协作** | 人主导，机器辅助 | 机器主导，人监督 |
| **关键挑战** | 操作效率、用户体验 | 可靠性、安全性 |
| **VIST优势** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |

**模仿学习数据采集的关键问题**:

1. **数据质量 vs 采集效率**:
   - 问题: 如何快速采集高质量数据？
   - VIST方案: 意图感知滤波 + 自适应引导，提高操作流畅度

2. **操作者疲劳**:
   - 问题: 长时间遥操作导致疲劳，数据质量下降
   - VIST方案: 视觉引导减轻操作者负担，α自适应调整辅助强度

3. **任务泛化**:
   - 问题: 不同任务需要不同的遥操作策略
   - VIST方案: α的三组分设计自动适应不同任务阶段

**工业遥操作装配的关键问题**:

1. **极高可靠性**:
   - 问题: 必须保证>99.9%成功率
   - VIST局限: 当前方案难以达到工业级可靠性

2. **力控需求**:
   - 问题: 装配需要精确力控（插入、拧紧）
   - VIST局限: 纯视觉方案无法提供力反馈

3. **安全认证**:
   - 问题: 工业应用需要安全认证
   - VIST局限: 研究原型，未经认证

**结论**: VIST更适合模仿学习数据采集

### 8. Baseline对比问题 📊

**问题描述**:
- 能简单复现AnyTeleop
- 有设备能复现ALOHA思路，但精度不如ALOHA
- 不复现别的系统怎么做性能对比？

**分析**:

**Baseline对比的三种策略**:

**策略1: 完整复现（最理想，但困难）**
- 优势: 公平对比
- 劣势: 需要相同硬件、大量时间
- 可行性: ❌ ALOHA需要高精度硬件（$50k）

**策略2: 部分复现 + 归一化对比（推荐）** ✅
- 方法:
  - 在你的硬件上实现ALOHA/AnyTeleop的核心算法
  - 对比相对性能提升，而非绝对性能
- 示例:
  ```
  ALOHA (原论文): 成功率 95% (高精度硬件)
  ALOHA (你的硬件): 成功率 60% (低精度硬件)
  VIST (你的硬件): 成功率 85% (低精度硬件)

  相对提升: (85-60)/(95-60) = 71% 的性能差距被弥补
  ```
- 优势: 公平、可行
- 可行性: ✅

**策略3: 消融实验（最可靠）** ✅
- 方法: 对比VIST的不同版本
  - Baseline: 直接映射（无滤波）
  - VIST-Basic: 固定增益卡尔曼滤波
  - VIST-Intent: 意图感知（α调制）
  - VIST-Full: 完整版（α + 冲突检测 + 置信度）
- 优势: 不依赖外部系统，证明每个模块的贡献
- 可行性: ✅✅✅

**推荐的对比实验设计**:

```
实验1: 消融实验（核心）
  ├─ Baseline: 直接映射
  ├─ +卡尔曼滤波: 固定增益
  ├─ +意图感知: α调制
  ├─ +冲突检测: β term
  └─ +置信度: c(t) 记忆

实验2: 方法对比（次要）
  ├─ AnyTeleop (在你的硬件上)
  ├─ ALOHA-style (在你的硬件上)
  └─ VIST (在你的硬件上)

实验3: 硬件对比（可选）
  ├─ 低成本硬件 ($500)
  └─ 高成本硬件 ($5k, 如果有条件)
```

**论文中如何呈现**:

"由于硬件限制，我们无法完全复现ALOHA的高精度设置。因此，我们采用**归一化对比**方法：在相同的低成本硬件上，对比VIST与简化版ALOHA的性能。结果显示，VIST在低成本硬件上达到了85%成功率，而简化版ALOHA仅为60%，**相对提升42%**。"
