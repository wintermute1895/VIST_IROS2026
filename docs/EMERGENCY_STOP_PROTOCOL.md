# 急停操作规范

## 软急停状态下的安全操作

### 风险说明
在软急停状态下持续发送控制指令可能导致：
1. 控制器状态冲突
2. 指令队列堆积
3. 解除急停后的突然运动
4. 电机控制器异常（极端情况下可能损坏硬件）

### 正确的操作流程

#### 1. 触发急停后
```bash
# 立即停止所有遥操作节点
# 按 Ctrl+C 停止以下终端：
# - Terminal 1: 外骨骼节点
# - Terminal 2: 滤波器节点
# - Terminal 4: 遥操作桥接节点
# - Terminal 5: 数据手套节点（如果启动）

# 保持运行的节点：
# - Terminal 3: 机械臂驱动（保持连接，但不发送指令）
# - Terminal 6: 灵巧手驱动（如果启动）
```

#### 2. 检查机器人状态
```bash
# 检查机械臂是否真的停止
ros2 topic echo /right_arm/joint_states --once

# 检查是否还有控制指令在发送
ros2 topic hz /right_arm/joint_follow
# 应该显示 "no messages received"
```

#### 3. 解除急停前的准备
1. 确认所有遥操作节点已停止
2. 确认机器人周围环境安全
3. 确认机器人当前姿态安全（不会突然倒下或碰撞）
4. 准备好随时再次按下急停

#### 4. 解除急停并重启系统
```bash
# 1. 在 Web 控制器解除软急停

# 2. 等待 2-3 秒，让控制器清空指令队列

# 3. 检查机器人状态
ros2 topic echo /right_arm/joint_states --once

# 4. 如果状态正常，重新启动遥操作节点
# 按照正常启动顺序：
# Terminal 1 -> Terminal 2 -> Terminal 4 -> Terminal 5 -> Terminal 6
```

### 紧急情况处理

#### 如果解除急停后机器人异常运动
1. **立即按下硬急停**（如果有物理急停按钮）
2. 或立即再次按下软急停
3. 断开机械臂电源（最后手段）

#### 如果控制器状态异常
```bash
# 1. 停止所有 ROS2 节点
pkill -9 ros2

# 2. 重启机械臂驱动
cd /home/ilex/Dev/VIST/external_sdk/arm_teleop
source install/setup.bash
ros2 run lbot_driver lbot_driver --ros-args \
  --params-file src/lbot_driver/config/lbot_config.yaml

# 3. 等待驱动完全初始化（约 5-10 秒）

# 4. 检查连接状态
ros2 topic list | grep right_arm

# 5. 如果正常，重新启动其他节点
```

### 预防措施

#### 1. 添加急停状态检测
在遥操作桥接节点中添加急停状态检测：
```python
# 伪代码示例
if robot.is_emergency_stopped():
    self.get_logger().warn("机器人处于急停状态，停止发送指令")
    return  # 不发送控制指令
```

#### 2. 添加心跳检测
```python
# 如果长时间没有收到机器人状态反馈，自动停止发送指令
if time.time() - last_state_time > 1.0:  # 1秒超时
    self.get_logger().error("机器人状态反馈超时，停止发送指令")
    self.stop_sending_commands()
```

#### 3. 添加指令速率限制
```python
# 限制指令发送频率，避免队列堆积
if time.time() - last_command_time < 0.05:  # 最快 20Hz
    return  # 跳过本次指令
```

## 硬件急停 vs 软急停

### 硬件急停（推荐）
- 物理断开电机电源
- 最安全，无状态冲突风险
- 需要重新上电和初始化

### 软急停（当前使用）
- 通过软件禁用电机驱动
- 响应快，但依赖软件正确实现
- 存在状态冲突的理论风险

### 建议
1. **优先使用硬件急停**（如果有物理按钮）
2. 软急停只用于非紧急情况的暂停
3. 在软急停状态下，**必须停止所有遥操作节点**

## 故障排查

### 问题：解除急停后机器人不响应
**可能原因：**
- 控制器状态异常
- 驱动节点崩溃
- 网络连接断开

**解决方法：**
1. 检查驱动节点是否运行：`ros2 node list | grep lbot_driver`
2. 检查话题是否发布：`ros2 topic list | grep right_arm`
3. 重启驱动节点
4. 检查网络连接：`ping 192.168.10.21`

### 问题：解除急停后机器人突然运动
**可能原因：**
- 指令队列堆积
- 遥操作节点未停止

**解决方法：**
1. 立即再次按下急停
2. 停止所有遥操作节点
3. 重启整个系统
4. 下次急停后记得停止遥操作节点

### 问题：频繁触发急停
**可能原因：**
- 控制指令过于激进
- 速度/加速度限制设置不当
- 机器人负载过大

**解决方法：**
1. 降低滤波器参数（增加平滑度）
2. 降低速度/加速度限制
3. 检查末端负载是否过重
4. 检查关节是否有机械阻力
