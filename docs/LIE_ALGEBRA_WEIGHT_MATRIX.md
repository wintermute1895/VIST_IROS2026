# 李代数权重矩阵设计

## 孔轴装配的各向异性约束

### 权重矩阵定义

对于孔轴装配任务，误差Twist的不同分量具有不同的重要性：

```
ξ_err = [v_x, v_y, v_z, ω_x, ω_y, ω_z]^T ∈ se(3)
         ↑    ↑    ↑    ↑    ↑    ↑
      径向 径向 轴向 倾斜 倾斜 旋转
```

### 任务相关的权重矩阵

```python
W = diag([w_radial, w_radial, w_axial, w_tilt, w_tilt, w_spin])

# 孔轴装配的典型权重
w_radial = 100.0  # 径向位置误差（严格约束）
w_axial  = 1.0    # 轴向位置误差（允许滑动）
w_tilt   = 50.0   # 倾斜角度误差（中等约束）
w_spin   = 0.1    # 绕轴旋转误差（几乎不约束）
```

### 物理意义

1. **径向约束（XY）**：孔的直径决定了径向容差（通常<1mm）
2. **轴向自由度（Z）**：插入过程允许沿轴线移动
3. **倾斜约束（ω_x, ω_y）**：倾斜会导致卡死，需要对齐
4. **旋转自由度（ω_z）**：圆形孔允许绕轴旋转

### 几何意图的计算

```python
d_geo² = (w_radial * (v_x² + v_y²) +
          w_axial * v_z² +
          w_tilt * (ω_x² + ω_y²) +
          w_spin * ω_z²)

α_dist = exp(-d_geo² / (2σ²))
```

### 扩展到其他任务

**拧螺丝**：
```python
w_radial = 100.0  # 严格径向约束
w_axial  = 10.0   # 轴向与旋转耦合
w_tilt   = 50.0   # 需要对齐
w_spin   = 5.0    # 旋转有约束（螺距）
```

**平面滑动**：
```python
w_radial = 1.0    # XY平面自由
w_axial  = 100.0  # Z方向严格约束
w_tilt   = 50.0   # 需要平行于平面
w_spin   = 0.1    # 旋转自由
```

## 方向对齐的李代数版本

### 问题：只用平移部分不够

原始定义只使用了Twist的平移部分：
```python
α_dir = 0.5 * (1 + <v_vel, v_err> / (||v_vel|| · ||v_err||))
```

这忽略了旋转运动的方向对齐。

### 解决方案：在se(3)上定义加权内积

定义两个Twist之间的加权内积：

```python
<ξ_1, ξ_2>_W = ξ_1^T · W · ξ_2

其中 ξ_1 = [v_1, ω_1]^T, ξ_2 = [v_2, ω_2]^T
```

### 方向对齐的完整定义

```python
# 误差Twist（从当前到目标）
ξ_err = ln(T_tcp^{-1} · T_target)

# 速度Twist（当前运动方向）
ξ_vel = [v_vel, ω_vel]^T

# 加权余弦相似度
cos_θ = <ξ_vel, ξ_err>_W / (||ξ_vel||_W · ||ξ_err||_W)

# 方向意图（归一化到[0,1]）
α_dir = 0.5 * (1 + cos_θ)
```

### 物理意义

- **cos_θ = 1**：操作者的运动方向完全对齐目标方向（包括平移和旋转）
- **cos_θ = 0**：运动方向正交于目标方向（探索性移动）
- **cos_θ = -1**：运动方向与目标相反（主动挣脱）

### 退化到平移情况

如果只关心平移（如当前VIST实现），设置：
```python
W = diag([1, 1, 1, 0, 0, 0])  # 只考虑平移
```

则自动退化到原始定义。

---

**关键洞察**：权重矩阵 W 编码了任务的几何约束结构，使意图因子能够区分"重要的误差"和"可容忍的误差"。
