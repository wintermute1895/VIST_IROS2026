# 参数作用说明

## 数据流和参数作用位置

```
人体关键点（从视觉节点）
    ↓
运动映射（motion_mapper）
    ↓
目标末端位姿（target_pos, target_quat）
    ↓                                    ← 仿真：红球和绿球显示这个位置
VIST求解（几何求解器）                      （不受任何速度限制）
    ↓
原始关节角度（q_solution）
    ↓
┌─────────────────────────────────────┐
│  安全控制器（SafeRobotController）    │
│  参数：max_joint_velocity = 0.3      │  ← 第一层限制
│       max_joint_acceleration = 0.5   │    （真机和仿真都有）
└─────────────────────────────────────┘
    ↓
安全关节角度（q_safe）
    ↓
    ├─→ 仿真：更新可视化（虚拟机械臂）
    │   （不使用 move_joint 参数）
    │
    └─→ 真机：发送到硬件
            ↓
        ┌─────────────────────────────────────┐
        │  硬件SDK（move_joint）                │
        │  参数：move_joint_speed = 0.25       │  ← 第二层限制
        │       move_joint_accel = 0.25        │    （只在真机）
        └─────────────────────────────────────┘
            ↓
        电机执行
```

## 参数对比

| 参数 | 作用位置 | 真机 | 仿真 | 限制对象 |
|------|---------|------|------|---------|
| max_joint_velocity | 安全控制器 | ✅ | ✅ | 关节角速度 |
| max_joint_acceleration | 安全控制器 | ✅ | ✅ | 关节角加速度 |
| move_joint_speed | 硬件SDK | ✅ | ❌ | 硬件轨迹速度 |
| move_joint_accel | 硬件SDK | ✅ | ❌ | 硬件轨迹加速度 |

## 仿真中的可视化元素

1. **红球（target_wrist）**
   - 显示：目标手腕位置
   - 来源：运动映射的输出
   - 限制：无（直接显示目标）

2. **绿球（target_elbow）**
   - 显示：目标肘部位置
   - 来源：运动映射的输出
   - 限制：无（直接显示目标）

3. **虚拟机械臂**
   - 显示：实际关节角度
   - 来源：经过安全控制器限制后的 q_safe
   - 限制：受 max_joint_velocity/acceleration 限制

## 为什么有两层限制？

**第一层（安全控制器）**：
- 软件层面的保护
- 防止算法输出危险的速度/加速度
- 真机和仿真都需要

**第二层（硬件SDK）**：
- 硬件层面的保护
- 控制电机的实际运动曲线
- 只在真机需要

## 调整建议

如果觉得运动太慢：
1. 先提高 max_joint_velocity（影响真机和仿真）
2. 再提高 move_joint_speed（只影响真机）
3. 两者都要提高才能让真机更快

当前配置：
- max_joint_velocity: 0.3 rad/s（第一层）
- move_joint_speed: 0.25 rad/s（第二层）
- 实际速度受限于较小的那个（0.25 rad/s）

建议：
- 如果要提高到 0.3 rad/s，两个参数都要 ≥ 0.3
- 或者保持一致：都设为 0.3
