# 机器人坐标系可视化工具使用说明

## 功能

这个工具可以帮助你：
1. 📊 可视化URDF机器人模型
2. 🎨 显示各个关节frame的坐标系（RGB = XYZ）
3. 📏 查看不同姿态下各frame的位置
4. 🔍 测量实际臂长

## 使用方法

### 1. 启动可视化工具

```bash
python scripts/visualize_robot_frames.py
```

### 2. 打开浏览器

工具启动后，会自动打开浏览器访问：
```
http://127.0.0.1:7000/static/
```

如果没有自动打开，请手动在浏览器中访问这个地址。

### 3. 查看坐标系

在MeshCat窗口中，你会看到：
- 🔴 **红色轴** = X轴（前）
- 🟢 **绿色轴** = Y轴（左）
- 🔵 **蓝色轴** = Z轴（上）

### 4. 切换姿态

在终端中按数字键切换不同姿态：
- `1` - 零位姿态 (全0)
- `2` - 手臂下垂
- `3` - 手臂前伸
- `4` - 手臂侧举
- `q` - 退出

### 5. 查看信息

每次切换姿态后，终端会显示：
- 当前关节角度
- 各重要frame的位置（X, Y, Z坐标）
- 臂长测量（上臂、前臂、总臂展）

## 重要Frame说明

| Frame名称 | 描述 | 用途 |
|----------|------|------|
| `base_link` | 基座 | 机器人坐标系原点 |
| `right_shoulder_pitch_link` | 肩部 | 肩关节位置，映射起点 |
| `right_elbow_pitch_link` | 肘部 | 肘关节位置 |
| `hand_base_link` | 手腕/末端执行器 | IK目标位置 |

## 坐标系定义

### 机器人Base_link坐标系
- **X轴（红色）**：向前为正
- **Y轴（绿色）**：向左为正
- **Z轴（蓝色）**：向上为正

### 零位姿态特点
- 所有关节角度为0°
- 手臂指向上方（Z轴正方向）
- 末端执行器在肩部上方约0.84m处

### 手臂下垂姿态特点
- 肩部pitch约28.6°，肘部pitch约-85.9°
- 手臂自然下垂
- 末端执行器仍在肩部上方（Z > 0）
- **注意**：机器人无法到达Z < 0的位置（肩部下方）

## 浏览器操作

在MeshCat窗口中：
- **鼠标左键拖动**：旋转视角
- **鼠标右键拖动**：平移视角
- **鼠标滚轮**：缩放
- **双击**：重置视角

## 故障排除

### 问题1：无法启动MeshCat
```
错误: 无法启动MeshCat可视化器
```

**解决方法**：
```bash
pip install meshcat
```

### 问题2：看不到机器人模型
```
⚠️ 警告: 无法加载可视化模型（可能缺少mesh文件）
```

**说明**：这是正常的，如果URDF中引用的mesh文件不存在，只会显示坐标系，不影响使用。

### 问题3：浏览器无法访问
- 检查端口7000是否被占用
- 尝试手动访问 `http://127.0.0.1:7000/static/`
- 确保防火墙没有阻止本地连接

## 理解坐标映射

通过这个工具，你可以直观地看到：

1. **肩部位置**：在零位姿态下，肩部在 `(0, -0.15, 0)`
2. **工作空间**：机器人只能到达Z ≥ 0的区域（肩部及以上）
3. **坐标轴方向**：
   - 红色X轴指向前方
   - 绿色Y轴指向左侧
   - 蓝色Z轴指向上方

这有助于理解为什么人体手臂向前伸时，MediaPipe的Z坐标增大应该映射到机器人的X坐标增大。
