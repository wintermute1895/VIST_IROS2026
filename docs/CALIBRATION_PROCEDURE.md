# VIST 真机测试标定流程

## 📋 概述

本文档详细说明 VIST 系统真机测试前的标定流程。标定是系统部署的**关键步骤**，直接影响任务成功率。

**标定目标**：将视觉坐标系与机器人坐标系精确对齐，误差 < 2mm

**预期时间**：首次标定 2-3 小时，后续标定 30-60 分钟

---

## 🎯 需要标定的内容

### 1. 相机内参标定 ⭐⭐⭐⭐⭐

**目的**：消除相机镜头畸变，获得准确的像素-物理坐标映射

**频率**：
- 首次使用：必须标定
- 更换相机/镜头：必须重新标定
- 日常使用：每月检查一次

**工具**：OpenCV 棋盘格标定

---

### 2. 手眼标定（Eye-to-Hand）⭐⭐⭐⭐⭐

**目的**：获得相机坐标系到机器人基座坐标系的变换矩阵

**频率**：
- 首次使用：必须标定
- 相机位置改变：必须重新标定
- 日常使用：每周检查一次，每月重新标定

**这是最关键的标定！** 误差分析显示这是主要瓶颈（±3-5mm）

---

### 3. TCP 偏置标定 ⭐⭐⭐⭐

**目的**：确定灵巧手/夹爪末端工具中心点（TCP）相对于机器人法兰的偏置

**频率**：
- 首次使用：必须标定
- 更换末端执行器：必须重新标定
- 日常使用：每两周检查一次

---

### 4. 目标物体标定 ⭐⭐⭐

**目的**：确定 AprilTag/ArUco 标签相对于 USB 插座的精确位置

**频率**：
- 首次使用：必须标定
- 更换标签/插座：必须重新标定
- 日常使用：每次实验前检查

---

## 🔧 详细标定流程

### 阶段 1: 相机内参标定（30-45 分钟）

#### 准备工作

**所需材料**：
- 棋盘格标定板（推荐：9×6 或 8×6，方格尺寸 20-30mm）
- 良好的照明环境
- OpenCV 标定脚本

**步骤**：

1. **采集标定图像**（15-20 分钟）
   ```bash
   # 运行标定图像采集程序
   python scripts/calibrate_camera_intrinsics.py --capture
   ```

   **采集要求**：
   - 采集 20-30 张不同角度和距离的棋盘格图像
   - 覆盖相机视野的各个区域（中心、边缘、角落）
   - 包含不同距离（近、中、远）
   - 确保棋盘格清晰，无运动模糊

   **质量检查**：
   - 每张图像都能检测到所有角点
   - 棋盘格占据画面的 30-70%
   - 避免过曝或欠曝

2. **计算内参矩阵**（5-10 分钟）
   ```bash
   # 运行标定计算
   python scripts/calibrate_camera_intrinsics.py --compute
   ```

   **输出**：
   - 相机内参矩阵 K (3×3)
   - 畸变系数 D (5×1 或 8×1)
   - 重投影误差（应 < 0.5 像素）

3. **验证标定质量**
   ```bash
   # 测试去畸变效果
   python scripts/calibrate_camera_intrinsics.py --test
   ```

   **验证标准**：
   - 重投影误差 < 0.5 像素 ✅
   - 去畸变后直线保持直线 ✅
   - 边缘区域无明显畸变 ✅

---

### 阶段 2: 手眼标定（60-90 分钟）⭐ 最关键

#### 准备工作

**所需材料**：
- 大尺寸 AprilTag 标签（推荐：tag36h11 family，尺寸 ≥ 100mm）
- 固定标签的平板或墙面
- 机器人处于可控状态

**重要提示**：
- 这是**最关键的标定**，直接影响系统精度
- 建议**标定 3 次**，取最佳结果
- 每次标定耗时约 30 分钟

#### 步骤

1. **固定 AprilTag 标签**（5 分钟）

   **位置要求**：
   - 放置在机器人工作空间内
   - 相机能清晰看到标签
   - 标签平面与桌面平行或垂直
   - 标签周围有足够的白色边框（≥ 1 个方格宽度）

   **固定方式**：
   - 使用胶带牢固粘贴
   - 确保标签完全平整，无弯曲
   - 标记标签位置（后续标定可重复使用）

2. **采集标定数据**（20-30 分钟）

   ```bash
   # 启动手眼标定数据采集
   python scripts/calibrate_hand_eye.py --mode collect
   ```

   **采集策略**：
   - **采集 20-30 个位姿**
   - 覆盖工作空间的不同区域
   - 包含不同的观察角度（正面、侧面、斜视）
   - 包含不同的距离（近、中、远）

   **每个位姿的操作**：
   ```
   1. 手动移动机器人到新位姿
   2. 确保相机能清晰看到 AprilTag
   3. 等待机器人静止（2-3 秒）
   4. 按空格键采集数据
   5. 系统自动记录：
      - 机器人末端位姿（从机器人控制器读取）
      - AprilTag 在相机中的位姿（视觉检测）
   ```

   **质量要求**：
   - AprilTag 检测成功率 100%
   - 标签占据画面的 20-60%
   - 标签无遮挡、无运动模糊
   - 覆盖工作空间的各个区域

3. **计算手眼变换矩阵**（5-10 分钟）

   ```bash
   # 计算手眼标定
   python scripts/calibrate_hand_eye.py --mode compute
   ```

   **算法选择**：
   - 推荐使用 **Tsai-Lenz** 方法（经典、稳定）
   - 或使用 **Park-Martin** 方法（精度更高）
   - OpenCV 提供多种方法，可以都尝试

   **输出**：
   - 相机到机器人基座的变换矩阵 T_cam_to_base (4×4)
   - 标定误差（应 < 3mm）
   - 每个位姿的重投影误差

4. **验证标定质量**（10-15 分钟）⭐ 非常重要

   ```bash
   # 验证标定精度
   python scripts/calibrate_hand_eye.py --mode verify
   ```

   **验证方法 1：重投影误差**
   - 使用标定数据计算重投影误差
   - **标准**：平均误差 < 3mm ✅
   - 如果 > 5mm，需要重新标定 ❌

   **验证方法 2：实际测试**
   ```
   1. 在工作空间放置一个已知位置的物体
   2. 用视觉系统检测物体位置
   3. 控制机器人移动到该位置
   4. 测量实际到达位置与目标位置的误差
   5. 标准：误差 < 5mm ✅
   ```

   **验证方法 3：多次标定对比**
   - 进行 3 次独立标定
   - 对比 3 次标定结果的差异
   - **标准**：3 次标定的平移差异 < 2mm，旋转差异 < 2° ✅
   - 选择误差最小的标定结果

5. **保存标定结果**

   ```bash
   # 保存标定参数
   python scripts/calibrate_hand_eye.py --mode save --name "calibration_2026_02_09"
   ```

   **保存内容**：
   - 变换矩阵 T_cam_to_base
   - 标定日期和时间
   - 标定误差统计
   - 采集的原始数据（用于后续分析）

---

### 阶段 3: TCP 偏置标定（30-45 分钟）

#### 方法 1: 手动测量（快速但精度较低）

**步骤**：

1. **测量物理尺寸**
   - 使用卡尺测量从机器人法兰中心到工具中心点的距离
   - 测量 X、Y、Z 三个方向的偏移
   - 重复测量 3 次，取平均值

   **精度**：±2-3mm

2. **配置文件设置**
   ```python
   # config/robot_config.yaml
   tcp_offset:
     x: 0.050  # 50mm
     y: 0.000
     z: 0.120  # 120mm
   ```

#### 方法 2: 视觉辅助标定（推荐，精度高）

**步骤**：

1. **准备标定工具**
   - 在 TCP 位置粘贴小型 AprilTag（10-20mm）
   - 或使用尖锐的标记笔标记 TCP 位置

2. **采集数据**
   ```bash
   python scripts/calibrate_tcp.py --mode collect
   ```

   - 移动机器人到 5-10 个不同位姿
   - 每个位姿用相机检测 TCP 位置
   - 记录机器人法兰位姿和 TCP 视觉位置

3. **计算 TCP 偏置**
   ```bash
   python scripts/calibrate_tcp.py --mode compute
   ```

   **精度**：±0.5-1mm

4. **验证**
   - 控制机器人移动到已知位置
   - 检查 TCP 实际位置与预期位置的误差
   - **标准**：误差 < 2mm ✅

---

### 阶段 4: 目标物体标定（15-30 分钟）

#### 步骤

1. **粘贴 AprilTag 标签**

   **位置选择**：
   - 粘贴在 USB 插座附近（距离 < 50mm）
   - 标签平面与插座平面平行
   - 标签清晰可见，无遮挡

   **尺寸选择**：
   - 推荐尺寸：30-50mm
   - 太小：检测不稳定
   - 太大：占据过多空间

2. **测量标签到插座的偏移**

   **方法 1：手动测量**
   ```
   1. 使用卡尺测量标签中心到插座中心的距离
   2. 测量 X、Y、Z 三个方向的偏移
   3. 重复测量 3 次，取平均值
   ```

   **方法 2：视觉辅助**
   ```bash
   python scripts/calibrate_target.py
   ```
   - 手动将机器人 TCP 对齐到插座中心
   - 记录此时的 TCP 位置
   - 检测 AprilTag 位置
   - 计算偏移量

3. **配置文件设置**
   ```python
   # config/target_config.yaml
   apriltag_to_socket_offset:
     x: 0.030  # 30mm
     y: 0.000
     z: 0.010  # 10mm
   ```

4. **验证**
   - 用视觉系统检测 AprilTag
   - 计算插座位置（AprilTag 位置 + 偏移）
   - 控制机器人移动到计算的插座位置
   - 检查对齐精度
   - **标准**：误差 < 3mm ✅

## 🔧 标定优化技巧

### 1. 提高手眼标定精度的技巧

**技巧 1：使用大尺寸 AprilTag**
- 推荐尺寸：≥ 100mm
- 大标签检测更稳定，精度更高

**技巧 2：增加采集位姿数量**
- 最少 20 个位姿
- 推荐 30-40 个位姿
- 更多数据 → 更高精度

**技巧 3：覆盖完整工作空间**
- 不要只在中心区域采集
- 包含边缘、角落位置
- 包含不同高度

**技巧 4：多次标定取最佳**
- 进行 3-5 次独立标定
- 对比误差，选择最佳结果
- 可以取平均（如果结果一致）

**技巧 5：使用高质量标定板**
- 打印清晰，无模糊
- 粘贴平整，无弯曲
- 周围有足够白色边框

### 2. 标定失败的常见原因

**问题 1：重投影误差过大（> 5mm）**

**可能原因**：
- 相机内参标定不准确 → 重新标定相机内参
- AprilTag 检测不稳定 → 使用更大的标签
- 机器人位姿读取不准确 → 检查机器人控制器
- 采集位姿分布不均匀 → 重新采集，覆盖完整空间

**问题 2：多次标定结果不一致（差异 > 5mm）**

**可能原因**：
- 标签粘贴不牢固，位置改变 → 重新固定标签
- 相机位置改变 → 固定相机
- 光照条件变化 → 使用稳定光源
- 采集数据质量差 → 提高采集质量

**问题 3：实际测试误差大（> 5mm）**

**可能原因**：
- TCP 偏置不准确 → 重新标定 TCP
- 目标物体偏移不准确 → 重新测量偏移
- 机器人重复定位精度差 → 检查机器人硬件
- 手眼标定本身不准确 → 重新标定

## 🎯 标定对系统性能的影响

根据误差分析（ERROR_ANALYSIS_AND_SUCCESS_RATE.md）：

### 当前标定精度（典型）

| 标定项目 | 误差 | 对总误差的贡献 |
|---------|------|---------------|
| 相机内参 | ±1-2mm | 低 |
| **手眼标定** | **±3-5mm** | **高（主要瓶颈）** |
| TCP 偏置 | ±1-2mm | 中 |
| 目标物体 | ±2-3mm | 中 |

### 优化后标定精度（目标）

| 标定项目 | 误差 | 改进方法 |
|---------|------|---------|
| 相机内参 | ±0.5-1mm | 高质量标定板 + 更多图像 |
| **手眼标定** | **±1-2mm** | **多次标定 + 更多位姿 + 大标签** |
| TCP 偏置 | ±0.5-1mm | 视觉辅助标定 |
| 目标物体 | ±1-2mm | 精确测量 + 视觉辅助 |

### 对任务成功率的影响

| 标定质量 | 算法对齐误差 | 人类微调后误差 | 任务成功率 |
|---------|-------------|---------------|-----------|
| 当前（典型） | 6.3mm | < 2mm | **95%** |
| 优化后 | 4.5mm | < 2mm | **98%** |
| 理想状态 | 3.0mm | < 2mm | **99%** |

**关键结论**：
- 手眼标定是主要瓶颈
- 优化手眼标定可以将成功率从 95% 提升到 98%
- 但即使标定不完美，柔顺接管机制也能有效补偿

## 🚀 快速开始指南

```bash
# 1. 相机内参标定

# 2. 手眼标定（重复 3 次，选最佳）

python scripts/calibrate_hand_eye.py --round 2

# 3. TCP 偏置标定
python scripts/calibrate_tcp.py

python scripts/calibrate_target.py

# 5. 验证所有标定
python scripts/verify_calibration.py --full
```

```bash
# 检查标定是否仍然有效
python scripts/verify_calibration.py --quick

# 如果误差 > 5mm，重新标定手眼
python scripts/calibrate_hand_eye.py --quick
```
