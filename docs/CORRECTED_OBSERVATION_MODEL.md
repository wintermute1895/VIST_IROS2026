## 2. 为什么绝对观测更优？

### 2.1 数值微分的噪声放大

**增量观测的噪声特性**:

假设传感器噪声为 ε ~ N(0, σ²)，则：
```
Δθ = (θ_t + ε_t - θ_{t-1} - ε_{t-1}) / Δt
```

噪声方差：
```
Var(Δθ) = Var(ε_t - ε_{t-1}) / Δt²
        = 2σ² / Δt²
```

在100Hz控制频率下（Δt = 0.01s）：
```
Var(Δθ) = 2σ² / 0.0001 = 20000σ²
```

**噪声被放大了20000倍！**

**绝对观测的噪声特性**:
```
θ_obs = θ_true + ε
Var(θ_obs) = σ²
```

噪声不被放大。

### 2.2 累积误差与漂移

**增量观测**:
```
θ_t = θ_0 + Σ(Δθ_i)
```
- 每一步的误差累积
- 长时间运行产生漂移
- 需要周期性重置

**绝对观测**:
```
θ_t = θ_obs,t
```
- 每次观测独立
- 无累积误差
- 自然抑制漂移

### 2.3 实现复杂度

| 特性 | 增量观测 | 绝对观测 |
|------|---------|---------|
| 数值微分 | 需要 | 不需要 |
| 历史维护 | 需要θ_{t-1} | 不需要 |
| 初始化 | 复杂 | 简单 |
| 漂移处理 | 需要重置机制 | 自然抑制 |
| 代码行数 | 更多 | 更少 |

### 2.4 数学等效性

在卡尔曼滤波框架下，两种方法是**数学等效**的：

**增量观测**:
```
z = Hx + v,  H = [0  I]
观测速度状态
```

**绝对观测**:
```
z = Hx + v,  H = [I  0]
观测位置状态
```

由于状态向量包含位置和速度，两种观测都能完整估计状态。

但在**工程实践**中，绝对观测的数值稳定性更好。

## 3. 修正后的数学模型

### 3.1 完整状态空间模型

**状态向量**:
```
x = [θ, θ̇]^T ∈ ℝ^14
```

**状态转移方程**（恒速度模型）:
```
x_{k+1} = F x_k + w_k

F = [I  Δt·I] ∈ ℝ^{14×14}
    [0   I  ]

w_k ~ N(0, Q(α, J))
```

**观测方程**（修正为绝对观测）:
```
z_k = H x_k + v_k

z_k = [θ_human,k, θ_virtual,k]^T ∈ ℝ^14

H = [I  0] ∈ ℝ^{14×14}
    [I  0]

v_k ~ N(0, R(α, δ))
```

### 3.2 自适应观测噪声协方差

**人类观测噪声** R_human(α):
```
R_human(α) = R_base × exp(λα)
```
- α→1（精确模式）: 高方差，抑制人类颤抖
- α→0（粗略模式）: 低方差，跟随人类意图

**虚拟引导噪声** R_virtual(α, δ):
```
R_virtual(α, δ) = R_min/(α + ε) + γ_c||δ||²
```
- α→1: 磁吸引（低方差）
- 高冲突δ: 增加方差，允许逃逸

**组合观测噪声**:
```
R(α, δ) = diag(R_human(α), R_virtual(α, δ)) ∈ ℝ^{14×14}
```

### 3.3 自适应过程噪声协方差

**各向异性过程噪声** Q(α, J):
```
Q(α, J) = diag(Q_θ(α, J), Q_θ̇)

Q_θ,i(α, J) = Q_base,i × freeze_factor_i(α, J)

freeze_factor_i(α, J) = 1.0 - freeze_strength × (1.0 - z_contribution_i)

z_contribution_i = |J_i · ẑ|  (第i个关节对Z方向的贡献)
```

当 α > 0.8 时激活Z轴锁定，冻结非插入自由度。

## 4. 论文修改建议

### 4.1 观测方程章节

**原文**（需修改）:
```
观测向量由人类意图增量和虚拟引导增量组成：
z_t = [Δθ_human, Δθ_virtual]^T
```

**修改为**:
```
观测向量由人类目标关节角度和虚拟引导目标角度组成：
z_t = [θ_human, θ_virtual]^T

其中 θ_human 是从人体关键点通过逆运动学解算得到的目标关节角度，
θ_virtual 是从虚拟引导位置通过微分逆运动学计算得到的目标角度。

注意：我们选择观测绝对角度而非角度增量，原因如下：
1. 避免数值微分带来的噪声放大
2. 消除累积误差和漂移
3. 提高数值稳定性
```

### 4.2 观测矩阵

**原文**（需修改）:
```
H = [0  I]
    [0  I]
```

**修改为**:
```
H = [I  0]
    [I  0]

观测矩阵H提取状态向量x = [θ, θ̇]^T中的位置分量θ。
虽然观测的是位置而非速度，但由于过程模型的动态性，
卡尔曼滤波器仍能准确估计速度状态θ̇。
```

### 4.3 添加工程考虑章节

建议在论文中添加一节"工程实现考虑"：

```
## 工程实现考虑

### 观测模型的选择

理论上，卡尔曼滤波可以观测位置或速度状态。我们选择观测绝对位置
而非速度增量，基于以下工程考虑：

1. **数值稳定性**: 速度增量需要数值微分，在高频控制（100Hz）下
   会显著放大传感器噪声。实验表明，微分操作使噪声方差增加
   O(1/Δt²) ≈ 10^4倍。

2. **累积误差**: 增量观测容易产生漂移，需要额外的重置机制。
   绝对观测每次都提供独立的位置信息，自然抑制漂移。

3. **传感器特性**: 视觉跟踪系统（如MediaPipe）直接输出关键点
   的绝对位置，而非速度。使用绝对观测可以直接利用传感器数据，
   无需额外处理。

4. **数学等效性**: 在卡尔曼框架下，观测位置状态与观测速度状态
   是等效的，因为状态向量同时包含位置和速度。过程模型的动态性
   确保了速度状态的可观性。

实验验证表明，绝对观测在噪声环境下的滤波性能优于增量观测，
同时实现复杂度更低。
```
