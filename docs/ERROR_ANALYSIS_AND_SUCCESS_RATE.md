# VIST 系统误差来源与任务成功率分析

## 📋 概述

本文档分析 VIST 系统的误差来源、误差传播链、以及预期任务成功率。

**分析日期**: 2026-02-09
**系统版本**: VIST v1.0（带冲突检测）

---

## 🎯 任务定义

**任务**：USB Type-A 插头插入 USB 插座

**成功标准**：
1. 插头正确对齐插座（位置误差 < 2mm，角度误差 < 5°）
2. 插入深度达到标准值（15mm ± 1mm）
3. 无硬件损坏
4. 操作时间 < 60秒

---

## 📊 误差来源分析

### 1. 视觉系统误差

#### 1.1 MediaPipe 手部跟踪误差

**来源**：
- 相机分辨率限制
- 光照条件变化
- 运动模糊
- 遮挡

**误差大小**：
- 位置误差：±1-2mm（典型）
- 位置误差：±3-5mm（极端情况）
- 频率：30Hz

**影响**：
- 人类指令计算不准确
- 冲突检测可能误触发
- 手部抖动被放大

**缓解措施**：
- ✅ One-Euro 滤波器（已实现）
- ✅ 零速死区（5mm/s）
- ✅ 冲突检测的速度阈值

**残余误差**：±0.5-1mm

---

#### 1.2 AprilTag/ArUco 目标检测误差

**来源**：
- 标定误差
- 相机畸变
- 标签打印精度
- 标签粘贴位置

**误差大小**：
- 位置误差：±2-3mm（典型）
- 位置误差：±5-8mm（极端情况）
- 角度误差：±2-3°

**影响**：
- 算法期望位置不准确
- 虚拟夹具引导偏离
- 需要人类微调修正

**缓解措施**：
- ✅ 柔顺接管（允许人类修正）
- ✅ 冲突检测（检测偏离）
- ⏳ 高精度标定（待优化）

**残余误差**：±1-2mm（有人类修正）

## 📈 误差传播链分析

### 误差累积模型

```
总误差 = √(误差1² + 误差2² + ... + 误差n²)  # RSS (Root Sum Square)
```

### 各阶段误差分析

#### 阶段 1: 人类主导接近（距离 > 5cm）

**主要误差来源**：
1. MediaPipe 手部跟踪：±1-2mm
2. SRS 映射：±2-3mm
3. IK 求解：±0.5-1mm
4. 机器人重复定位：±0.5-1mm

**累积误差**：
```
总误差 = √(2² + 3² + 1² + 1²) = √15 ≈ 3.9mm
```

**影响**：
- 🟢 低影响（距离大，误差可接受）
- 人类可以通过视觉反馈自然修正

---

#### 阶段 2: 算法主导对齐（距离 < 5cm）

**主要误差来源**：
1. AprilTag 检测：±2-3mm
2. 手眼标定：±3-5mm
3. TCP 偏置：±1-2mm
4. IK 求解：±0.5-1mm
5. 机器人重复定位：±0.5-1mm

**累积误差**：
```
总误差 = √(3² + 5² + 2² + 1² + 1²) = √40 ≈ 6.3mm
```

**影响**：
- 🟡 **中等影响**（可能需要人类微调）
- USB Type-A 插座容差：±2mm
- **超出容差，需要柔顺接管修正**

---

#### 阶段 2.5: 人类微调（柔顺接管）

**主要误差来源**：
1. 人类视觉判断：±1-2mm
2. 人类手部抖动：±0.5-1mm（滤波后）
3. 系统响应延迟：±1-2mm

**累积误差**：
```
总误差 = √(2² + 1² + 2²) = √9 = 3mm
```

**影响**：
- 🟢 低影响（人类可以精确修正）
- **修正后误差 < 2mm，满足插入要求**

---

#### 阶段 3: 自动插入（深度控制）

**主要误差来源**：
1. 深度测量：±0.5-1mm
2. 插入阻力：±1-2mm
3. 机器人控制精度：±0.5-1mm

**累积误差**：
```
总误差 = √(1² + 2² + 1²) = √6 ≈ 2.4mm
```

**影响**：
- 🟢 低影响（USB 插入深度容差：±2mm）
- **满足要求**
