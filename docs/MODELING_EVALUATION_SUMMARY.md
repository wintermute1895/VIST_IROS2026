## 需要修正的问题

### 🔴 1. 观测模型维度不一致（关键问题）

**你的定义**：
```
观测向量：z_k ∈ R^{14} (关节位置+速度)
观测方程：z_k = H·x_k + v_k，其中 H = I_{14}
```

**问题**：
- 这意味着你直接观测关节角度
- 但实际上，人类指令和视觉引导都在**任务空间**（$\mathbb{R}^3$）

**修正**：
```python
# 正确的观测模型
z_h_task ∈ R^3  # 人类指令（任务空间位置）
z_v_task ∈ R^3  # 视觉引导（任务空间位置）

# 观测方程（非线性）
z_task = FK(q) + v  # 正运动学

# 观测矩阵（雅可比）
H_k = J(q_pred) ∈ R^{3×7}  # 不是 I_{14}
```

**影响**：
- 需要使用EKF（而非线性KF）
- 每次更新都要计算雅可比矩阵

### 🔴 2. 信息融合空间不明确

**你的公式**：
```
R_eff^{-1} = R_h^{-1} + R_v^{-1}
z_syn = R_eff · (R_h^{-1}·z_h + R_v^{-1}·z_v)
```

**问题**：$\mathbf{z}_h$ 和 $\mathbf{z}_v$ 在哪个空间？

**修正**：明确在任务空间融合
```python
# 任务空间融合
R_h_task(α) = R_base · exp(λ_h · α)
R_v_task(α, δ, c) = R_min/((α+ε)·(c+ε)) + λ_escape·δ²

R_eff_task^{-1} = R_h_task^{-1} + R_v_task^{-1}
z_syn_task = R_eff_task · (R_h_task^{-1}·z_h_task + R_v_task^{-1}·z_v_task)

# 然后用EKF更新关节空间状态
```

### 🟡 3. 雅可比伪逆的奇异性

**你的公式**：
```
Q_constraint = J†(q) · Σ_se3 · (J†(q))^T
```

**问题**：
- 当机器人接近奇异构型时，$\mathbf{J}$ 秩亏
- 伪逆不稳定

**修正**：使用阻尼最小二乘
```python
J_dagger = J^T · (J·J^T + λ_damp·I)^{-1}  # λ_damp = 0.01
```
