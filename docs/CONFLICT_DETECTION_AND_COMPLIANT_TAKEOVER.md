# VIST 冲突检测与柔顺接管 (Conflict Detection & Compliant Takeover)

## 📋 概述

本文档描述 VIST 系统的核心创新：**冲突检测（β term）** 和 **柔顺接管（Compliant Takeover）**。

这个设计使得 VIST 从单纯的"遥操作"升级到了**"人机共享控制 (Shared Control) 的高级范式"**。

---

## 🎯 核心创新

### 1. 冲突因子 β

**定义**：β 表示人类-算法意图冲突程度

- **β = 0**：无冲突（人类和算法方向一致）
- **β = 1**：完全冲突（人类和算法方向相反）

**计算方法**：

```python
def compute_conflict(human_command, algorithm_expectation, velocity):
    """
    计算冲突因子 β

    β = f(θ, v)
    其中：
    - θ: 人类指令和算法期望的夹角
    - v: 人类移动速度（表示"抵抗"强度）
    """
    # 1. 归一化向量
    human_dir = human_command / ||human_command||
    algo_dir = algorithm_expectation / ||algorithm_expectation||

    # 2. 计算夹角 θ
    cos_theta = dot(human_dir, algo_dir)
    theta = arccos(cos_theta)

    # 3. 计算角度冲突分量（0 → 1）
    angle_conflict = theta / π

    # 4. 计算速度冲突分量（0 → 1）
    velocity_conflict = clip(velocity / 0.05, 0, 1)

    # 5. 综合冲突因子
    if theta > 30° and velocity > 0.5cm/s:
        β = angle_conflict × velocity_conflict
    else:
        β = 0

    return β
```

---

### 2. 修正的意图因子

**原始公式**：
```
α = f(v, d)  # 基于速度和距离
```

**修正公式**（带冲突检测）：
```
α_effective = α × (1 - β)
```

**效果**：
- 当 **β = 0**（无冲突）：α_eff = α（正常工作）
- 当 **β = 1**（完全冲突）：α_eff = 0（人类完全接管）
- 当 **0 < β < 1**（部分冲突）：α_eff 介于两者之间（柔顺接管）

---

### 3. 柔顺接管 (Compliant Takeover)

**定义**：人类可以随时通过"抵抗"算法来接管控制，无需显式切换模式。

**工作原理**：

1. **正常情况**（β = 0）：
   - 算法主导对齐（α = 1）
   - 虚拟夹具引导机器人朝向目标
   - 人类只需保持手部稳定

2. **检测到冲突**（β > 0）：
   - 人类开始朝与算法不同的方向移动
   - β 增大，α_eff 降低
   - 算法逐渐"让步"，允许人类接管

3. **完全接管**（β → 1）：
   - 人类强烈"抵抗"算法
   - α_eff → 0
   - 系统完全跟随人类指令

4. **恢复算法主导**（β → 0）：
   - 人类停止"抵抗"
   - β 降低，α_eff 恢复
   - 算法重新接管控制

## 🔧 实现细节

### 1. 冲突检测条件

**触发条件**：
```python
# 只在算法主导阶段检测冲突
if state in [VISUAL_ADMITTANCE, CONSTRAINED_INSERTION]:
    # 计算冲突因子
    β = compute_conflict(...)
else:
    β = 0  # 其他阶段不检测冲突
```

**阈值参数**：
- **角度阈值**：30°（夹角超过 30° 才认为是冲突）
- **速度阈值**：0.5cm/s（速度超过 0.5cm/s 才认为是"抵抗"）

### 2. 观测融合

**原始融合**：
```python
z_total = (1 - α) * z_human + α * z_virtual
```

**修正融合**（带冲突检测）：
```python
α_eff = α × (1 - β)
z_total = (1 - α_eff) * z_human + α_eff * z_virtual
```

**示例**：
- **α = 1, β = 0**：z_total = z_virtual（算法主导）
- **α = 1, β = 0.5**：z_total = 0.5 * z_human + 0.5 * z_virtual（50-50 混合）
- **α = 1, β = 1**：z_total = z_human（人类接管）

### 3. 状态转换

**新增状态**：`CORRECTION_OVERRIDE`（修正/接管）

**状态转换逻辑**：
```python
if state == VISUAL_ADMITTANCE:
    # 检测到持续冲突 → 进入修正/接管状态
    if β > 0.5 for 1 second:
        state = CORRECTION_OVERRIDE
        α = 0.2  # 降低算法权重

elif state == CORRECTION_OVERRIDE:
    # 冲突消失 → 恢复视觉导纳状态
    if β < 0.2 for 1 second:
        state = VISUAL_ADMITTANCE
        α = 1.0  # 恢复算法主导
```

## 📊 实验场景

### 场景 1: 标定精度不足

**问题**：
- 手眼标定精度 ±5mm
- 算法引导的位置偏离实际插孔 3mm

**解决方案**（柔顺接管）：
1. 算法主导对齐（α = 1）
2. 人类发现位置偏离，开始微调
3. 系统检测到冲突（β = 0.6）
4. α_eff = 1 × (1 - 0.6) = 0.4
5. 系统 40% 跟随算法，60% 跟随人类
6. 人类成功修正位置
7. 冲突消失（β → 0），算法恢复主导

**优势**：
- ✅ 无需显式切换模式
- ✅ 平滑过渡，无突变
- ✅ 人类保持控制感

### 场景 2: 动态障碍物

**问题**：
- 算法引导机器人朝向目标
- 突然出现障碍物（如人手）

**解决方案**（柔顺接管）：
1. 算法主导对齐（α = 1）
2. 人类发现障碍物，快速拉回手部
3. 系统检测到强烈冲突（β = 0.9）
4. α_eff = 1 × (1 - 0.9) = 0.1
5. 系统几乎完全跟随人类，快速避障
6. 障碍物消失，人类恢复正常移动
7. 冲突消失（β → 0），算法恢复主导

**优势**：
- ✅ 快速响应（< 100ms）
- ✅ 安全性高
- ✅ 无需紧急停止

### 场景 3: 人类探索

**问题**：
- 人类不确定插孔位置
- 想要手动探索周围区域

**解决方案**（柔顺接管）：
1. 算法主导对齐（α = 1）
2. 人类开始探索性移动（左右、上下）
3. 系统检测到持续冲突（β = 0.7）
4. 自动进入 CORRECTION_OVERRIDE 状态
5. α = 0.2，主要跟随人类
6. 人类完成探索，找到正确位置
7. 冲突消失，恢复算法主导

**优势**：
- ✅ 支持人类探索
- ✅ 保留算法辅助（平滑滤波）
- ✅ 自动恢复
