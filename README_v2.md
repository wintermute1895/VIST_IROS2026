## 🎯 系统概览

VIST (Vision-based Intent-aware State Teleoperation) 是一个用于精密遥操作任务的人机共享控制框架。

| 创新点 | 描述 | 论文潜力 |

| **冲突检测与柔顺接管** | 无模式切换的平滑权重调整 | RSS/HRI |
| **仿生几何求解器** | O(1) 复杂度的解析 IK | RA-L |

## 🔬 数学理论总结

### 1. 运动映射 (Motion Mapping)

**核心公式**:
```
Z = v_fore / ||v_fore||
Y = (Z × v_knuckle) / ||Z × v_knuckle||
X = Y × Z
R_target = [X | Y | Z]
```

**理论保证**: 指节向量与前臂向量的夹角 ∈ [15°, 165°]，避免奇异点。

### 2. VIST 卡尔曼滤波

**状态空间模型**:
```
x = [θ, θ̇]^T ∈ R^14
x_{k+1} = F·x_k + w_k
z_k = [Δθ_human, Δθ_virtual]^T
```

**意图驱动协方差调度**:
```
R_human(α) = R_base + (R_max - R_base) × (1 - α)
R_virtual(α) = R_base - (R_base - R_min) × (1 - α)
```

### 3. 冲突检测

**核心公式**:
```
θ = arccos(v_human · v_algo)
β = (θ / π) × clip(v_human / v_threshold, 0, 1)
α_eff = α × (1 - β)
```

**物理意义**: β 量化人机冲突程度，α_eff 实现平滑权重调整。

### 4. 几何求解器

**层级解耦**:
```
Stage 1: q1-q4 (臂部配置)
  - 肩部 3 个关节 + 肘部 1 个关节
  - 使用球坐标和余弦定理

Stage 2: q5-q7 (腕部姿态)
  - 使用 ZYX 欧拉角分解
```

**复杂度**: O(1)，比数值优化快 10-100 倍
