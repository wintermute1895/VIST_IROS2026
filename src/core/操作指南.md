# LinkerHand L10 配置系统说明

## 概述

本系统现已支持完整的配置化管理，所有参数都在配置文件中设置默认值。

**重要**: 可以直接运行 `python scripts/run_hand.py` 而无需任何命令行参数！

系统特性：
- 统一的配置文件 (`src/core/config.py`)
- 多种摄像头支持（OpenCV标准摄像头 + Intel RealSense D435i）
- 多组抓取预设（小/中/大物体）
- 所有参数可通过配置文件或命令行参数设置

## 快速开始

### 1. 直接运行（使用配置文件默认值）
```bash
python scripts/run_hand.py
```

这将使用 `src/core/config.py` 中的所有默认设置。

### 2. 修改配置文件
编辑 `src/core/config.py` 来更改默认设置：

```python
# 例如：切换到RealSense摄像头
class CameraConfig:
    CAMERA_TYPE: CameraType = CameraType.REALSENSE  # 改为REALSENSE

# 例如：使用大物体抓取预设
class JointAnglesConfig:
    DEFAULT_GRASP_PRESET: GraspPreset = GraspPreset.LARGE  # 改为LARGE

# 例如：提高控制频率
class ControlConfig:
    CONTROL_FREQ: int = 60  # 改为60Hz
```

### 3. 使用命令行参数覆盖配置
命令行参数可以临时覆盖配置文件中的值：

```bash
# 临时使用RealSense摄像头
python scripts/run_hand.py --camera-type realsense

# 临时使用大物体预设
python scripts/run_hand.py --grasp-preset large

# 组合使用
python scripts/run_hand.py --camera-type realsense --grasp-preset large --freq 60
```

## 配置文件结构

配置文件位于 `src/core/config.py`，包含以下配置类：

### 1. CameraConfig - 摄像头配置
```python
CAMERA_TYPE: CameraType = CameraType.OPENCV  # 摄像头类型
OPENCV_CAMERA_ID: int = 0                     # OpenCV摄像头ID
OPENCV_FRAME_WIDTH: int = 640                 # 图像宽度
OPENCV_FRAME_HEIGHT: int = 480                # 图像高度
OPENCV_FPS: int = 30                          # 帧率

REALSENSE_WIDTH: int = 640                    # RealSense分辨率
REALSENSE_HEIGHT: int = 480
REALSENSE_FPS: int = 30
REALSENSE_ENABLE_DEPTH: bool = True           # 是否启用深度流
REALSENSE_ALIGN_TO_COLOR: bool = True         # 深度对齐到彩色
```

### 2. VisionConfig - 视觉控制器配置
```python
MIN_DETECTION_CONFIDENCE: float = 0.5         # MediaPipe检测置信度
MIN_TRACKING_CONFIDENCE: float = 0.5          # MediaPipe追踪置信度
RATIO_THRESHOLD_IDLE: float = 0.8             # IDLE状态阈值
RATIO_THRESHOLD_GRASP: float = 0.2            # GRASP状态阈值
DEBOUNCE_FRAMES: int = 5                      # 防抖帧数
FORCE_IDLE_DURATION: int = 30                 # 强制IDLE持续帧数
```

### 3. HardwareConfig - 硬件驱动配置
```python
CAN_ID: int = 0x27                            # CAN设备ID
CAN_CHANNEL: str = "can0"                     # CAN接口名称
MOCK_MODE: bool = False                       # 模拟模式
ENABLE_FILTERING: bool = True                 # 启用过滤
```

### 4. ControlConfig - 控制系统配置
```python
CONTROL_FREQ: int = 30                        # 控制循环频率（Hz）
WINDOW_NAME: str = 'LinkerHand L10 - 视觉控制'
WINDOW_WIDTH: int = 640
WINDOW_HEIGHT: int = 480
```

### 5. JointAnglesConfig - 关节角度预设配置

包含三组抓取预设，每组包含 idle、pre_grasp、grasp 三个状态：

#### 小物体预设 (GRASP_PRESET_SMALL)
适用于：硬币、螺丝、小零件等
- 使用拇指和食指精确夹持
- 其他手指保持张开

#### 中等物体预设 (GRASP_PRESET_MEDIUM) - 默认
适用于：杯子、瓶子、手机等
- 使用拇指、食指、中指抓取
- 平衡的抓取力度

#### 大物体预设 (GRASP_PRESET_LARGE)
适用于：球、盒子、大瓶子等
- 使用所有手指包裹抓取
- 更大的开口和抓取范围

## 使用方法

### 1. 基本使用（OpenCV摄像头 + 中等物体预设）
```bash
python scripts/run_hand.py
```

### 2. 使用Intel RealSense D435i摄像头
```bash
python scripts/run_hand.py --camera-type realsense
```

**注意**: 需要先安装 pyrealsense2:
```bash
pip install pyrealsense2
```

### 3. 使用不同的抓取预设
```bash
# 小物体抓取
python scripts/run_hand.py --grasp-preset small

# 中等物体抓取（默认）
python scripts/run_hand.py --grasp-preset medium

# 大物体抓取
python scripts/run_hand.py --grasp-preset large
```

### 4. 运行时切换抓取预设

在程序运行时，可以使用键盘快捷键切换预设：
- 按 `1` - 切换到小物体抓取预设
- 按 `2` - 切换到中等物体抓取预设
- 按 `3` - 切换到大物体抓取预设

### 5. 其他命令行参数
```bash
# 模拟模式（无硬件）
python scripts/run_hand.py --mock

# 使用不同的OpenCV摄像头
python scripts/run_hand.py --camera 1

# 更改控制频率
python scripts/run_hand.py --freq 20

# 调试模式
python scripts/run_hand.py --log-level DEBUG

# 组合使用
python scripts/run_hand.py --camera-type realsense --grasp-preset large --freq 20
```

## 键盘控制

运行时可用的键盘快捷键：
- `q` - 退出程序
- `r` - 重置机械手到IDLE位置（完全张开）
- `s` - 打印系统状态
- `1` - 切换到小物体抓取预设
- `2` - 切换到中等物体抓取预设
- `3` - 切换到大物体抓取预设

## 自定义配置

### 修改配置参数

编辑 `src/core/config.py` 文件，修改相应的配置类：

```python
# 例如：修改控制频率
class ControlConfig:
    CONTROL_FREQ: int = 60  # 改为60Hz

# 例如：修改状态机阈值
class VisionConfig:
    RATIO_THRESHOLD_IDLE: float = 0.85  # 更严格的IDLE阈值
    RATIO_THRESHOLD_GRASP: float = 0.15  # 更严格的GRASP阈值
```

### 自定义抓取预设

在 `JointAnglesConfig` 类中修改预设角度：

```python
GRASP_PRESET_SMALL: Dict[str, List[float]] = {
    'idle': [255.0, 255.0, ...],      # 10个关节角度
    'pre_grasp': [200.0, 80.0, ...],  # 10个关节角度
    'grasp': [150.0, 90.0, ...]       # 10个关节角度
}
```

关节顺序：
1. 拇指俯仰 (Thumb_Pitch)
2. 拇指偏航 (Thumb_Yaw)
3. 食指俯仰 (Index_Pitch)
4. 中指俯仰 (Middle_Pitch)
5. 无名指俯仰 (Ring_Pitch)
6. 小指俯仰 (Pinky_Pitch)
7. 食指侧摆 (Index_Roll)
8. 无名指侧摆 (Ring_Roll)
9. 小指侧摆 (Pinky_Roll)
10. 拇指侧摆 (Thumb_Roll)

角度范围：0-255度

## 摄像头支持

### OpenCV标准摄像头
- 支持USB摄像头、笔记本内置摄像头等
- 自动配置分辨率和帧率
- 无需额外依赖

### Intel RealSense D435i
- 支持RGB彩色流
- 支持深度流（可选）
- 支持深度对齐到彩色图像
- 需要安装 pyrealsense2 库

## 架构说明

### 新增模块

1. **config.py** - 配置管理
   - 集中管理所有系统参数
   - 支持多种配置类
   - 提供配置访问接口

2. **camera_wrapper.py** - 摄像头包装器
   - 统一的摄像头接口
   - 支持多种摄像头类型
   - 工厂模式创建摄像头实例

### 更新模块

1. **vision_controller.py**
   - 使用配置文件参数
   - 支持多组抓取预设
   - 支持运行时切换预设

2. **run_hand.py**
   - 使用配置文件参数
   - 支持摄像头类型选择
   - 支持抓取预设选择
   - 新增键盘快捷键

## 故障排除

### RealSense摄像头无法打开
1. 确认已安装 pyrealsense2: `pip install pyrealsense2`
2. 确认摄像头已连接并被系统识别
3. 检查USB端口是否为USB 3.0

### 配置修改不生效
1. 确认修改了正确的配置文件 `src/core/config.py`
2. 重新启动程序
3. 检查是否有命令行参数覆盖了配置

### 抓取预设效果不理想
1. 根据实际物体大小选择合适的预设
2. 在 `config.py` 中微调关节角度
3. 使用 `s` 键查看当前状态和角度
